# 随便按吧 · 颜色与音符

一个给小朋友（1–5 岁）乱按的网页玩具：**每按一下键盘、点一下鼠标、划一下触摸板，就绽放一朵彩色颜料，同时响起一个音符。**

参考了 [Typatone](https://typatone.com/) 的「按键即音乐」内核，外观换成了粉彩纸面 + 糖果色厚笔刷的幼儿友好风格。
纯静态页面，**零依赖、零构建、零网络请求**，不联网也能玩，没有广告、没有追踪、没有输入框。

---

## 怎么打开

1. 双击 `index.html`（用 Chrome 或 Edge 最稳）。
2. 点中间的圆形按钮，或者随便按一个键 → 自动进入全屏开始玩。
3. 想退出全屏：**F11**（部分浏览器也支持 Esc）。

> 不需要装任何东西，也不需要起本地服务器（脚本用经典 `<script>` 加载，`file://` 直接能跑）。

## 玩法

| 操作 | 效果 |
|---|---|
| 键盘乱按 | 溅出一团颜料 + 一个音符。音高按**物理键位**排布，全部锁在 C 大调五声音阶里，怎么乱按都成调 |
| 空格 / 回车 | 特别大的一团，加一串闪粉 |
| 方向键 | 朝那个方向甩出一道长笔触，末端再溅开 |
| 长按不放 | 只会有轻微的小点脉动，不会刷屏、不会爆音 |
| 鼠标点一下 | 大飞溅 + 三音和弦 + 闪光粒子 |
| 鼠标 / 触摸板拖动 | 粗笔刷画彩虹线，甩出零散小点，边走边响 |
| 鼠标划过（不按） | 留下淡淡的湿笔迹，一会儿蒸发 |
| 鼠标滚轮 / 触摸板双指滑动 | 洒落一排气泡状滴点 + 上扬的气流声 |
| 触屏多指 | 每根手指各画各的颜色 |
| 画满一屏 | **自动洗画**：画布被颜料占到 55%（或已经 75% 满）时，等手停一下就开始洗，约 1.8 秒擦成干净白纸；一直不停手也会在涂鸦量到顶时强行洗 |
| **Ctrl + Shift + X** | **立刻清屏**，秒回一张干净白纸（别名：Ctrl + Shift + Delete）。这是给家长用的，其他功能键仍然全部屏蔽 |

打开时就是**一张干净的白纸**，第一次按键/点击才落下第一团颜料。

没有分数、没有关卡、没有文字、没有按钮 —— 只有因果反馈。

## 屏蔽了什么（重点）

页面对**所有**按键默认行为做了拦截，只保留两个后门：

- 拦掉（按下不产生任何作用、也不出声）：`Shift` `Ctrl` `Alt` `Win` `CapsLock` `NumLock` `Insert` `Home` `End` `PgUp` `PgDn` `Tab` `Esc` `PrintScreen` `F1–F10` `F12`，以及任何 `Ctrl/Alt/Cmd` 组合键（Ctrl+W / Ctrl+R / Ctrl+T / Ctrl+S / Ctrl+Shift+I …）、`Backspace`、`F5`。
- 鼠标/触摸板：右键菜单、中键自动滚动、双击选中与缩放、拖拽、文本选择、长按菜单、双指缩放、下拉刷新、滚动，全部屏蔽。
- **保留 F11**：切换全屏。全屏成功后还会尝试调用 `navigator.keyboard.lock()`（Chrome/Edge），把 Esc 和更多系统键也交给页面处理。
- **保留 Ctrl + Shift + X / Ctrl + Shift + Delete**：立刻清屏（家长用）。小孩乱按很难凑齐这个组合。
- 关闭标签页或刷新时会弹一次确认框（防止手滑），点「离开」即可正常关闭。

### 拦不住的（系统级，任何网页都做不到）

`Win` 键、`Alt+Tab`、`Alt+F4`、`Ctrl+Alt+Del` 属于操作系统，网页无权屏蔽。

想要更强的「锁定」效果：

- **Windows + Chrome/Edge**：全屏 + 本页的键盘锁已能挡掉绝大部分；再稳妥可以打开系统的「专注助手」或用平板模式。
- **iPad**：设置 → 辅助功能 → 引导式访问（Guided Access），连点三下侧边键开启。
- **Android**：设置里搜「屏幕固定 / Screen pinning」。

## 小贴士

- **改了代码后一定要 Ctrl + F5 强刷**：`file://` 打开时 Chrome 也会缓存 js，看到"改了没生效"基本都是这个原因。脚本链接已经带了 `?v=3` 版本号。
- 想确认洗画逻辑真的在跑：地址后加 `?debug=1`，左上角会显示实时「覆盖 % / 阈值 / 负荷」。
- 自动洗画的阈值都在 `js/main.js` 顶部：`WASH_AT`（默认 0.55）、`LOAD_AT`、`LOAD_FORCE`、`WASH_TIME`。
- 声音有点吵？调系统音量即可。
- 页面切到后台会自动挂起音频，回来再自动恢复。
- 窗口大小变了，已经画的内容会保留并按比例缩放。
- 所有声音都限制在五声音阶 + 压缩限幅，音量上限被压得比较低，不会突然炸耳朵。

## 部署到 GitHub Pages（0 元，网页上传即可）

**上线步骤看 [UPLOAD.md](UPLOAD.md)**，按你 `sad-notes` 那套流程走。两条路：

- **方式 A（推荐）**：`node tools/bundle.mjs` 生成单文件 `dist/index.html`，只上传这一个文件到仓库根目录 → 完事。不会漏文件、不用管目录、也不会有 js 缓存问题。
- **方式 B**：把 `index.html` + `css/` + `js/` 整个目录拖上去，保留源码结构。

然后 仓库 → Settings → Pages → Source `Deploy from a branch` → `main` / `/ (root)` → Save，等 1~3 分钟打开
`https://<你的用户名>/<仓库名>/`。

纯静态站，所以：不用买服务器、不用备案、自动 HTTPS、免费额度（1GB 仓库 / 每月 100GB 流量）够用一辈子。

## 文件结构

```
index.html          入口 + 开始页
css/style.css       纸纹背景、糖果色、圆角卡片
js/guard.js         按键/鼠标默认行为屏蔽、F11 全屏、Keyboard Lock
js/audio.js         WebAudio 音色合成、五声音阶、限速与限幅
js/blob.js          颜料飞溅图形生成（不规则色块 + 尖瓣 + 流挂 + 喷点）
js/effects.js       漂浮音符、闪粉、光环、湿笔迹、会眨眼的小脸、空闲泡泡
js/main.js          分层画布、输入分发、自动淡出、空闲待机、demo 模式
```

## 实现备注

- 两层画布：`#paint` 累积留色（便宜，只画一次），`#fx` 每帧清空重画粒子和音符。
- 自动洗画靠**实测覆盖率**：每 0.8 秒把画布缩到 160×100 数一次"有颜料的像素占比"，超过 58% 就开始擦；擦的过程中每 0.3 秒复测，擦到 4% 以下直接收尾 `clearRect`，所以不会留下淡影鬼影，也不会因为用鼠标画而不触发。
- 性能上限：DPR 最高 2；音符 80 个、闪粉 260 个、小脸 26 个上限；每秒最多 20 个新音、同时最多 26 个声部。
- 长时间乱按不会爆内存：颜料会被自动洗掉，动态对象都有长度上限。
- 没有 >3Hz 的闪烁（避免光敏风险）。
